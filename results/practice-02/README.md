# Результати практичної роботи №2

## Мета експерименту

Порівняти продуктивність алгоритмів AES-128-GCM, AES-256-GCM та ChaCha20-Poly1305 у бібліотеках `cryptography` і `PyCryptodome`.

## Методика

Експеримент проведено для трьох розмірів даних: 1 KiB, 64 KiB та 1 MiB.

Параметри запуску:
- Кількість прогрівальних операцій: 10.
- Кількість серій вимірювань: 5.
- Операцій у кожній серії: 100.
- Розмір контексту AAD: 64 байти.
- Створення об'єкта шифру включено до часу вимірювання.

Вимірювалися операції шифрування та розшифрування. Результати містять медіанний час виконання та пропускну здатність.

## Файли результатів

- `raw.csv` — 180 записів вимірювань.
- `report.json` — 36 агрегованих результатів.
- `chart_throughput.png` — порівняння пропускної здатності шифрування.
- `chart_operation_time.png` — порівняння медіанного часу операцій.

## Основні результати

У проведеному експерименті `cryptography` показала вищу пропускну здатність порівняно з `PyCryptodome` для всіх досліджених комбінацій алгоритмів і розмірів даних.

Найвище виміряне значення пропускної здатності шифрування становило 2746,65 MiB/s для AES-128-GCM у бібліотеці `cryptography` на даних розміром 64 KiB.

Для даних розміром 1 MiB найвище значення пропускної здатності шифрування отримано для AES-256-GCM у `cryptography` — 1367,96 MiB/s.

Найнижчу пропускну здатність серед наведених результатів показав ChaCha20-Poly1305 у `PyCryptodome` на даних розміром 1 MiB — 202,01 MiB/s під час шифрування.

## Висновки

Результати показують, що продуктивність залежить від алгоритму, бібліотеки та розміру даних.

У межах цього експерименту `cryptography` продемонструвала кращі показники пропускної здатності, ніж `PyCryptodome`. Водночас не можна визначити один універсально найшвидший алгоритм для всіх розмірів даних та операцій.

Оскільки створення об'єкта шифру включено до вимірювання, отримані показники характеризують реалізований сценарій виконання, а не лише швидкість внутрішніх криптографічних операцій.

Результати є вимірюваннями конкретного запуску на конкретному обладнанні.
